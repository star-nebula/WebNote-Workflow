# 别让 AI 自己查自己：我用四个 Agent 搭了一条可信的网页笔记流水线

> 摘要：AI 帮你读文章、做笔记很爽，但它会一脸自信地编造事实，而你根本看不出来。本文分享一个"网页笔记四步工作流"——把整理、提炼、独立核查、人工确认拆成四个 Agent 分工协作。核心不是自动化，而是"可控的自动化"：AI 可以无限地建议，但凡要落地动手，都停在我这道闸前。

---

## 一、当 AI 开始一本正经地胡说

我有个习惯：看到好文章就存进稍后读，周末集中"消化"。后来我偷懒，把这一堆网页直接丢给 AI，让它帮我提炼要点、写进笔记。效率确实上来了，直到有一次我回头翻笔记，发现一条数据怎么看都不对劲——它写"某报告称采用率同比翻倍"，可我明明记得原文说的是"稳步增长约 8%"。

我回去翻原文，确认了：原文根本没说翻倍。是 AI 在提炼时，把"增长"脑补成了"翻倍"，还写得理直气壮。

这之后我查了几条旧笔记，又揪出两处类似的"原创事实"。问题不在于 AI 故意骗我，而是它把"听起来对"的当成了"对的"写进去了。更可怕的是：**让同一个 AI 去核查它自己的笔记，它查不出来**——它不知道自己是怎么想的，只会顺着自己的逻辑圆场。

于是我意识到，问题不在模型够不够聪明，而在流程有没有"防自己"的设计。

## 二、三道闸：把"可信"拆进流程里

我重新设计这条流水线时，只盯着一个目标：**让 AI 编的东西尽可能被拦下来**。为此加了三道闸。

**第一道闸：分工隔离。** 把"整理 → 提炼 → 核查 → 确认"拆成四个独立的 Agent，每个拥有干净的上下文。提炼的只管从正文里提要点，不碰核查；核查的只拿"原文 + 笔记成品"逐条比对，不掺和提炼时的思路。上下文一隔离，"想包庇自己都做不到"。

**第二道闸：独立核查。** 这是整套里最容易被跳过、也最关键的一道。核查 Agent 必须是一个全新的上下文，一份没参与过提炼的"白纸"。它只做一件事：把笔记里每一条要点、每个数字、每个结论，回到原文逐条比对，对不上的标"可疑 / 原文无依据"。经验告诉我，凡是省掉这一步的，假信息迟早进知识库。

**第三道闸：确认闸。** 前面三道再能干，也只是把活干完、把建议摆好。按不按那个"确认"键，从头到尾是我。所有删除、归档、发布、写入长期记忆的动作，都停在"待确认"，我逐条点过头才落地。

一句话总结这套哲学：**AI 可以无限地"想"和"建议"，但凡要"落地动手"，停在我这道闸前。**

## 三、四个 Agent 各管一段

- **Agent 1 · 整理**：把你存好的网页（标题 + 网址 + 正文）登记成一张清单，做初步四选一分类——学习（能上手的方法）、借鉴（写法结构）、内容补充（补事实数据）、可归档（信号低或重复）。它不提炼、不下结论，只负责"读进来、归类"。没有正文的，如实标"无"，绝不拿标题硬凑。
- **Agent 2 · 提炼**：从有正文的页面里提取 3–5 条核心要点，每条标注在正文里的位置（第几段、哪句话附近），再给一句"为什么值得保留"和修订建议。铁律是只依据正文，正文里没有的数字、结论一律不写。
- **Agent 3 · 核查**：拿提炼的笔记，逐条回到原文比对。对得上的标"已核实"，对不上或原文里根本找不到的标"可疑"，并说清冲突在哪。它是全新的 Agent，不和提炼的那个是同一个，所以不会替它辩护。
- **Agent 4 · 确认**：把前三道的产出汇总成一份"待确认提案"，每条给建议动作（保留 / 修正 / 删除）和理由。它被标"可疑"的条目会单独列出，等我逐条核对。全部停在待确认，不自动执行任何动作。

## 四、三种用法，零门槛到全自动

这套流程不挑工具，按你手头的 AI 挑一种：

1. **多 Agent 版（推荐）**：如果你用的工具支持 subagent（比如 WorkBuddy、Claude Code、Codex），把调度器提示词连同工作流文档一起丢给它，它会自动创建四个独立 Agent 接力跑完。
2. **单对话框版（零门槛）**：只有普通对话框也行。关键是"分段交付"——第一段做整理+提炼后停下；第二段必须新开一个对话，把核查提示词 + 原文 + 笔记贴进去跑核查；第三段再回来做确认。核查换新对话这一步不能省，否则就又变成自己查自己。
3. **文件流水线**：把四个 Agent 做成文件流水线，每次运行在 `runs/` 下建一个 `YYYY-MM-DD-主题` 子目录，四个输出文件并列写入，多次运行互不覆盖，原文只读不改。

关于"怎么把正文弄进来"：我**不让 AI 现去抓网页**。直接抓十有八九抓不全，付费墙和要登录的页更抓不到。我用自己的浏览器桥接工具（BrowserSkill，腾讯开源，能操作我已登录的浏览器）或剪藏插件把正文存好，再交给 Agent。正文这种又脏又不稳的活，交给成熟的工具；AI 只干它擅长的归类和判断。

## 五、它真的帮我拦住过假信息

这套不是纸上谈兵。我用它处理过一批网页，跑完四步后，核查 Agent 真的在核查表里标出了几条"原文无依据"的推论——其中有的是我之前凭印象以为"原文说过"的。如果不是独立核查这一道，这些就会被我当真存进知识库，还不知道错在哪。

而且因为每次运行都落盘成四个清晰的 Markdown 文件（整理清单、笔记、核查表、待确认提案），我可以自己翻、自己核对，整个过程透明、可逆。错了撤得回来，比盲信一个"全能助手"踏实得多。

## 六、谁适合用这套工作流

- 你习惯大量收藏网页 / 文章，但"存了等于读了"的收藏夹吃灰党；
- 你把 AI 当研究助手，又不想被它一本正经地误导；
- 你在做知识管理、写周报、做选题库，需要可溯源的素材；
- 你认同"自动化要可控"——愿意为可靠性，多花那一步确认的成本。

如果你只是偶尔让 AI 总结一篇微信文章，那没必要上这套。但只要你开始把 AI 的产出当"知识"积累，独立核查和确认闸就不是可选项，而是必选项。

## 小结

AI 做笔记的瓶颈，从来不是"能不能提炼"，而是"提炼的东西你敢不敢信"。把流程拆成四个各管一段的 Agent，用分工隔离上下文、用独立核查拦住编造、用确认闸把最终决定权留在自己手里——这套"网页笔记四步工作流"没让 AI 变得更聪明，但让它的产出变得**可信**。

如果你也想试试，工作流文档和可直接复用的提示词都已经开源，欢迎拿去改。下一步我打算把它做成可一键加载的 Skill，改一处所有工具一起生效。也欢迎在评论区聊聊：你被 AI 的"原创事实"坑过吗？
